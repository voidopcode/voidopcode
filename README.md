### hey, I'm void

Low-level developer. I like taking consoles apart in software: system libraries, GPU code, file formats.

**Now working on:** Vilocity, Xbox Series X|S games running natively on Windows. No CPU emulation: the game's x64 code runs as-is, the console's system libraries are re-implemented, and its RDNA2 GPU code is recompiled to Direct3D 12 shaders. First target: GTA VI (boots, menus, saves and the world load; rendering in progress).

**Into:** emulation · GPU shader translation · reverse engineering · systems programming

**Tools:** Rust · Direct3D 12 · DXIL / HLSL · Windows internals
